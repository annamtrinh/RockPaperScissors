# Rock Paper Scissors

A Java console game where you play Rock Paper Scissors against the
computer and keep track of wins, losses, and ties across rounds.

## Features
- Computer picks a random move each round
- Running score for wins, losses, ties, and games played
- Play-again option
- Input validation (no crashes on bad input)

## Concepts Used
- while loops and boolean flags
- if / else if conditions with logical operators (&&, ||)
- Random numbers with `Math.random()`
- Arrays for choice names
- User input with `Scanner` and `try/catch`

## How to Run
```
javac RockPaperScissors.java
java RockPaperScissors
```
